# Agent In Your World

> 把 AI agent 接进 Minecraft 的桥，并给它一具真的能干活的身体。

## 这是什么

这是一个**让 AI agent 操作 Minecraft** 的模组。

模组本体启动一个本地 HTTP + WebSocket 服务（默认 `127.0.0.1:38121`），把游戏能力暴露成
标准 MCP 工具；agent 通过工具读取世界、执行命令、操作玩家。从 0.3 起，它还能为 agent
生成一具**没有客户端连接、但服务端和其他玩家都当作正常玩家**的身体。

它不是「游戏内 AI 助手」，也不是语音助手。它提供的是**接口**：把运行中的客户端变成
agent 可以直接操作的进程。具体说什么、怎么想，取决于连上来的 agent。

> **注意：目前只有 DeepSeek Harness 有完整配套。**
> 模组暴露的 MCP 与 WebSocket 是通用的，任何 MCP 客户端都能连；但游戏内聊天唤醒、
> `/agent` 的模式与会话转发、chat 模式的语气注入这些功能，是围绕 DeepSeek Harness 实现的。
> 换用其他 harness 需要自行编写对接层。

## 主要功能

### 1. 世界读取与操作

- 读取玩家、实体、方块、方块实体 NBT、容器内容
- 执行服务端命令并取回输出
- 截图（仅客户端）、粒子高亮、向游戏内发送消息
- 监听方块放置 / 破坏事件，监视指定机器的 NBT 变化

### 2. Agent 的身体

模组可以生成一个 `ServerPlayer`：它有无客户端连接，但拥有独立的背包、生命值、游戏模式，
在服务端与其他玩家眼中是一个普通玩家。

| 能力 | 说明 |
|---|---|
| 行走 | 给坐标即可，A* 寻路，会绕障碍、跨 2~3 格空档、跳上台阶 |
| 挖掘 | 按工具与方块硬度计时，掉落正常，走原版的左键与保护判定 |
| 放置 | 正常右键，会依据朝向与碰撞选择面 |
| 使用 | 吃、喝、投掷、开箱、拉杆、门 |
| 战斗 | 正常伤害与击退，会掉血 |
| 跟随 | 持续跟随指定玩家，距离变化时自动重新规划路线 |
| 递交 | 把背包物品放到指定玩家脚下，或朝其抛出 |
| 闲置 | 无指令时会转头看向附近玩家、东张西望、蹲下、原地跳 |

### 3. 两种模式

```
/agent work    全部工具可用；改世界还需 allowWrite=true
/agent chat    保留身体动作，拒绝改世界、执行命令、传送
```

chat 模式在**工具入口**强制，而不是靠 agent 自觉；agent 无法自行切回 work，
只有玩家能在游戏内输入。

### 4. 三种权限闸门

| 闸门 | 作用 |
|---|---|
| `enabled` | 服务本身是否启动 |
| `allowWrite` | 是否允许改世界、生成身体、改背包 |
| `allowCommands` | 是否允许执行游戏命令 |

三者独立，默认全部关闭。

## 使用流程

1. 将 jar 放入 `mods/`，启动游戏
2. 首次启动会生成 `config/agentinminecraft.json`，其中包含随机 token
3. 用支持 MCP 的客户端连接 `http://127.0.0.1:38121/mcp`，请求头带
   `Authorization: Bearer <token>`
4. 需要身体时，打开对应闸门后调用生成接口

配置可在游戏内修改，不必手改文件：

```
/agent config                          查看全部（token 打码）
/agent config set allowWrite true      改一项并写盘
/agent config reload                   重读配置
```

## 配置说明（常用项）

| 字段 | 默认值 | 说明 |
|---|---|---|
| `enabled` | `true` | 是否启动服务 |
| `host` / `port` | `127.0.0.1` / `38121` | 监听地址，仅回环 |
| `token` | 随机 48 位 | 认证令牌，除 `/health` 外所有请求都要 |
| `allowWrite` | `false` | 世界写入、生成身体、改背包 |
| `allowCommands` | `true` | 执行游戏命令 |
| `playerName` | `Dafeiyu` | 身体的玩家名 |
| `agentName` | 空 | 游戏内发言使用的名字，空则用 `playerName` |
| `skinFile` / `skinPlayer` / `skinModel` | 空 / 空 / `auto` | 本地皮肤 |
| `greetOnJoin` | `true` | 玩家进入时是否发送提示 |

## 环境与兼容

| 项 | 要求 |
|---|---|
| Minecraft | 1.21.1 |
| 加载器 | NeoForge 21.1.x |
| 环境 | **客户端与服务端**（客户端可用截图与皮肤；服务端可用其余功能） |

| 外部依赖 | 无（不依赖其他模组） |

## 已知限制

- **目前只有 DeepSeek Harness 有完整配套**（见开头说明）
- 皮肤是**客户端行为**：只有安装了本模组的客户端能看到自定义皮肤，其他客户端看到默认皮肤
- 模组**不自带皮肤**，首次生成的身体使用默认外观
- 服务默认只监听回环地址；暴露到局域网需要自行修改并承担风险
- 假玩家的身体不保存背包，重启游戏后需要重新生成

## 安全性

- 默认监听 `127.0.0.1`，不接受外部连接
- 所有请求（除 `/health`）需要 Bearer token
- 写操作、命令执行、传送分别由独立开关控制，默认关闭
- chat 模式下的拒绝发生在工具入口，不依赖 agent 自律
